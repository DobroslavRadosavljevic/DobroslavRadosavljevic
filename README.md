# Hey there! 👋

I'm **Dobroslav**, a full-stack developer passionate about building modern web applications and developer tools.

I work primarily with TypeScript across the entire stack, from React frontends to Bun-powered backends. I enjoy creating open-source tools, exploring new technologies, and building products that solve real problems.

## 🛠️ Tech Stack

### Languages & Runtime

- 🟦 **TypeScript** - My primary language for everything
- 🥟 **Bun** - Fast JavaScript runtime & package manager

### Frontend

- ⚛️ **React 19** - UI library with the latest features
- ▲ **Next.js 16** - Full-stack React framework
- 🎨 **Tailwind CSS 4** - Utility-first styling
- ✨ **Motion** - Animations and transitions
- 📝 **Tiptap** - Rich text editing

### Backend

- 🦊 **Elysia** - Bun-native web framework with end-to-end type safety
- 🔗 **oRPC** - Type-safe RPC with OpenAPI support
- 🗄️ **Drizzle ORM** - TypeScript-first database toolkit
- 🐘 **PostgreSQL** - Primary database
- 🔴 **Redis** - Caching, sessions, and job queues
- 📬 **BullMQ** - Background job processing

### AI & Integrations

- 🤖 **Vercel AI SDK** - Unified API for multiple AI providers
- 🧠 **OpenAI, Anthropic, Google, Groq, Mistral** - LLM integrations
- 🔊 **ElevenLabs** - Voice AI

### Infrastructure & Tooling

- ⚡ **Turborepo** - Monorepo build system
- 🐳 **Docker** - Containerization
- ☁️ **Vercel** - Frontend deployment
- 🔶 **Cloudflare Workers** - Edge computing
- 📦 **AWS S3** - Object storage
- 🔍 **Sentry** - Error monitoring
- ⏰ **Trigger.dev** - Background jobs
